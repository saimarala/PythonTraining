slice operator
--------------------------------
s[begin index:end index: step] --> s[10:100:1]
Begin Index - Specifies the starting position of the slice (substring)
End Index - Specifies the termination position of the slice (substring)
Step - The interval between elements (optional). the step controls how many elements to skip when traversing the sequence. By default step value is 1
    If +ve → forward direction left to right consider begin to end-1
    If -ve → backward direction → right to left consider begin to end+1.

If we are not specifying begin index then it will consider from beginning of the string.
If we are not specifying end index then it will consider up to end of the string.
If we are not specifying both begin and end indexes then slice will consider whole string.
if endindex is out of range then slice operator will never raise index error rather it will consider
Full string starting from begin index in both forward and reverse directions.
